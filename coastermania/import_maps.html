CoasterMania · Guide

Import a custom map

Drop a .glb model onto your headset and CoasterMania will offer it as an environment — a scan of your own room, a model you found online, or something you built yourself.

Where the file goes

One folder on the headset's internal storage. CoasterMania creates it for you the first time it runs, so it's already there waiting.

Drop folder

Internal shared storage / Android / data / com.FourthWallStudios.CoasterMania / files / Environments

Android/data/com.FourthWallStudios.CoasterMania/files/Environments

Format
.glb only. It's the one 3D format CoasterMania can open while the game is running — .fbx, .obj and .gltf won't be listed.
Location
Files must sit directly inside Environments. Anything in a subfolder is ignored.
Naming
The file name becomes the name you see in game. Living Room.glb shows up as Living Room.
Refresh
No restart needed. The folder is re-read every time you open the environment picker, so you can add a file with the headset still on.

Getting the file across

Either route works — use whichever is in front of you.

  1. From a computer, over USB

    Plug the headset in, then put it on and accept the Allow access to data prompt — nothing appears on the computer until you do. The headset then shows up as a drive. Navigate to the path above and copy your .glb in.

  2. On the headset itself

    Open the Files app, go to Internal storage, and follow the same path. Useful if you downloaded a model in the headset's browser — move it out of Downloads and into Environments.

  3. Pick it in game

    Start a new world and step through the environment carousel past the built-in ones. Your imports appear at the end, listed by file name.

If your file doesn't appear

It's almost always one of three things: the extension isn't .glb, the file landed in a subfolder, or it's still sitting in Downloads. Only .glb files at the top level of that folder are listed.

Scanning your own room

A phone scan of a real space is the most striking thing you can put in here — your coaster running through your actual living room. Scaniverse is free on iOS and Android and exports the format we need.

  1. Scan the space

    Walk the room slowly, sweeping the phone back across surfaces you've already covered — that overlap is what lets it stitch the space together. Even lighting helps; strong sun through a window tends to punch holes in the result.

  2. Export as GLB

    Once processing finishes, use Scaniverse's share or export option and choose GLB from the format list. The other formats will export happily, but CoasterMania won't list them.

  3. Move it to the headset

    Get the file onto a computer — AirDrop, a cable, or any cloud drive — then copy it into the Environments folder using the path above.

Keep the texture size down

Scanning apps routinely export a single 8192 × 8192 texture, which unpacks to roughly 340 MB in memory. CoasterMania automatically shrinks anything larger than 2048 px, but it still has to decode the original first — so a scan exported at a lower texture resolution loads noticeably faster. If Scaniverse offers a quality or resolution choice on export, medium is usually plenty for a room you're standing in.

Where to find models

Anything that exports to GLB will work. A few good places to start:

Sketchfab

The largest library of downloadable 3D scenes, with a big Creative Commons section and GLB among the standard download formats. Filter by Downloadable, and check the licence before using anything publicly.

Polycam

Another phone scanning app, with a public gallery of community scans — real places captured by other people, many of them downloadable.

Poly Haven

Free, no-attribution assets. Smaller, and focused more on individual models and environments than whole scenes, but everything there is genuinely unrestricted.

Blender

If you'd rather build one: Blender is free and exports GLB directly via File → Export → glTF 2.0, choosing the .glb binary option.

Scale and orientation

CoasterMania places you at the model's own origin and treats it as a life-size space, so a model authored in centimetres will feel enormous and one authored at miniature scale will feel like a dollhouse. If a map feels wrong the moment you arrive, rescale it in Blender and re-export — that's usually all it needs.

Still stuck? Use the Report a bug button in the game's menu and tell us what you tried — including the file name and where the model came from.
